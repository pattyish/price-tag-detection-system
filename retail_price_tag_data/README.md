# Retail Price Tag Detection Dataset

This dataset is organized for YOLO-based price tag detection.

## Structure

- `raw/`: original source image and YOLO labels
- `processed/`: augmented/normalized images and labels
- `train/`: 70% training split
- `val/`: 15% validation split
- `test/`: 15% testing split
- `dataset.yaml`: YOLO dataset configuration

## Class

| ID | Class |
|---:|-------|
| 0 | price_tag |

## Important Note

This is a starter synthetic dataset generated from the provided shelf image and augmented variations.  
For a stronger GitHub/portfolio project, expand this with real store images and manually verified labels.
